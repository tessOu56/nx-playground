# Auth — portal login redirect

Organizer and attendee identity lives on **event-portal** Better Auth (`/api/auth/*`). This Vite app on `:3004` only redirects bookmarks to `http://localhost:3000/zh-TW/login`.

```bash
pnpm dev:auth
```

See [`docs/runbooks/identity.md`](../../docs/runbooks/identity.md).
