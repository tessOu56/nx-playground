# Security and upgrade-risk audit — 2026-10-19

Scope: `nx-playground` event stack (`event-portal`, `event-cms`, `api-server`, `auth`, shared libs used by those apps). Production C-end: [nx-event-portal.vercel.app](https://nx-event-portal.vercel.app) (LINE Login/LIFF, Messaging webhook `/api/line/webhook`, Neon catalog). Recent merged work reviewed: PRs #32–#35. Rebased onto main after #37–#41; catalog/detail URL sanitizing is #41's `publicHttpsUrl` (LINE catalog-search reuses it).

Dependabot/CodeQL/secret-scanning alert APIs were **not readable** with this integration (`403`). Open Dependabot PRs **#29** and **#30** (`github/codeql-action` 4.38.0 → 4.38.3) were left untouched.

## Fixes in this change

| Issue | Why it was high | Change |
| --- | --- | --- |
| LINE token endpoint trusted client `redirect_uri` | `/api/line/auth/token` is a **public client-secret proxy**. A stolen authorization code plus an attacker-chosen registered redirect could be exchanged server-side. | Ignore body `redirect_uri`. Compute callback with `getLineRedirectUri()` from the portal request origin / env (same rule as the browser). |
| Token endpoint had no PKCE | Same proxy: anyone who intercepts `code` (logs, Referer, extension) could POST it and get tokens. | Browser Login now sends S256 `code_challenge`; exchange **requires** a 43–128 char `code_verifier`. OAuth `state` is CSPRNG (`crypto.getRandomValues`), not `Math.random()`. |
| Refresh token returned to the browser | LINE `refresh_token` was JSON’d to the client and stored in `localStorage` (XSS = long-lived LINE session theft). Nothing in the portal refreshed with it. | Stop returning `refreshToken`. Access/ID tokens still return for the existing SPA session. |
| Token/ID-token routes accepted any `Origin` | Cross-site pages could drive the secret proxy. | Reject `Origin` that is not this deployment, `NEXT_PUBLIC_SITE_URL`, or `NEXT_PUBLIC_LINE_REDIRECT_URI`. |
| LINE error bodies / 500 `error.message` leaked to clients | Token failures echoed LINE’s `error_description` (and internal exceptions). | Generic 400/500 messages. |
| Webhook 401 coverage + oversized body | Invalid HMAC was tested; missing header, body swap, and huge payloads were not. Unbounded `request.text()` can pin memory. | HMAC over raw bytes (`arrayBuffer`), 256 KiB cap → **413**, extra rejection tests. Missing secret returns generic `Webhook is not configured`. |
| Collector URL + image SSRF | `fetchMocExhibitions(url)` would fetch any host; `httpsImageUrl` stored any `https:` URL (localhost, `169.254.169.254`, userinfo). LINE Flex then asks LINE to fetch the image. | Pin fetch to `cloud.culture.tw` HTTPS, `redirect: 'error'`. Drop private/link-local/credentialed image and source URLs. Drop IP/localhost images in catalog Flex mapping. |
| axios `1.12.2` / `^1.11.0` | Multiple 2026 axios highs (DoS via `mergeConfig`/`__proto__`, HTTP/2 DNS/proxy bypass, prototype-pollution gadgets). `^1.11` could also have resolved to yanked malicious **1.14.1**. | Pin **axios@1.20.0**. Do not install `1.14.1` / `0.30.4`. |
| swiper `12.0.1` | Critical prototype pollution [CVE-2026-27212](https://github.com/advisories/GHSA-hmx5-qpq5-p643) (`extend()` / `Array.prototype.indexOf` bypass). Used by portal carousel. | Pin **swiper@12.1.2** (published patch). |
| Nest mutating APIs unauthenticated | `POST/PUT/DELETE /api/events`, `POST /api/orders/:id/confirm`, `POST /api/tickets/:id/check-in` could inject/delete Neon catalog rows or confirm tickets. Ticket checkout is retired (ADR-012 / exhibition discovery). | `AdminBearerGuard`: `Authorization: Bearer` must match env `ADMIN_API_TOKEN` via `timingSafeEqual`. **Unset token → 401 on every mutating request.** |
| ECPay webhook / mock-complete | `applyWebhook` marked orders paid with no CheckMacValue. Mock `GET /payments/mock-complete/:id?outcome=paid` did the same. | Both return **404 in production** unless `ALLOW_NONPROD_PAYMENTS=true`. If the webhook is reachable, **CheckMacValue** is verified (fail closed when `ECPAY_HASH_KEY` / `ECPAY_HASH_IV` are unset). |

Tests: webhook signature rejections, token PKCE / redirect pin / Origin / no refresh token, PKCE S256, collector allowlist, image URL blocks, Nest admin bearer fail-closed, ECPay MAC round-trip/tamper, production payment-callback 404. CI `.github/workflows/p2-line-bot.yml` runs LINE Login + collector + `nx test @nx-playground/api-server`.

## Findings that were already in good shape

- **Webhook HMAC**: `x-line-signature` = HMAC-SHA256(raw body, channel secret), `timingSafeEqual` with length check (`libs/line/bot/signature.ts`). Route uses raw bytes, not `JSON.parse` before verify.
- **ID token**: official `https://api.line.me/oauth2/v2.1/verify` plus local `iss` / `aud` (Login channel ID) / `exp` / optional nonce. Leftover employer channel `2007835339` is rejected. Fail-closed on network/JSON errors.
- **SQL**: Neon tagged templates in `catalog-search.ts`; Prisma parameterized upserts. Keyword already clipped to 80 chars in `parseCatalogQuery`. ILIKE wildcards in user keywords are a logic nuisance, not SQL injection.
- **Exhibition HTML**: collector decodes entities **once** then strips tags; portal renders description as React text (`EventInfoHeader`), not `dangerouslySetInnerHTML`. JSON-LD `EventJsonLd` exists but is **unused**.
- **Secrets in git**: no private keys, `AKIA`, `ghp_`, `github_pat_`, or `sk_live_` in history. Current tree hits are local docker `postgresql://event:event@127.0.0.1:5433/...` in examples. `.env` is gitignored.

## Remaining risks (ranked)

### High

None remaining in this pass. Nest event writes / order confirm / ticket check-in require `ADMIN_API_TOKEN`. Payment webhook and mock-complete are 404 in production unless `ALLOW_NONPROD_PAYMENTS=true`; a reachable webhook verifies CheckMacValue.

### Medium

3. **No rate limits** on `/api/line/webhook`, `/api/line/auth/token`, `/api/line/auth/id-token`, Nest public GETs. HMAC makes webhook CPU cheap for unsigned junk; token/verify can still hammer LINE and this function. Prefer Vercel Firewall / WAF over in-process maps (serverless). **Effort:** small–medium (platform), large if app-level Redis.

4. **SPA session in `localStorage`** (`nx-playground_liff_user_info` still holds `accessToken` + `idToken`). PKCE stops code theft; **XSS still steals the LINE access token**. Move to httpOnly cookies / server session. **Effort:** large (behavior change).

5. **Labelled-demo BFF** (`/api/[...path]`) is an unauthenticated in-memory checkout/check-in API on the Hobby portal. Documented as not the funds path; still IDOR on demo tickets and a confusing public surface. Don’t point `DATABASE_URL` at this process. **Effort:** small (auth gate or disable outside demo).

6. **ID token nonce is optional** when the caller omits it. LIFF replay until `exp`. Require nonce for LIFF verify. **Effort:** small.

7. **JsonLd XSS footgun**: `JSON.stringify` inside `<script type="application/ld+json">` does not escape `<`. Unused for catalog today; if wired to MoC titles, `</script>` breaks out. Serialize with `\u003c`. **Effort:** small.

8. **Supabase anon JWT in `specs/BACKEND/QUICKSTART.md`** (role `anon`, not `service_role`). Public-by-design, but it is a real project ref. Don’t add `service_role`. Profile app is out of event-stack feature scope. **Effort:** small (redact or rotate if RLS is weak).

9. **Production Next.js has no security headers** (`X-Content-Type-Options`, `Referrer-Policy`, `frame-ancestors`). Dev sets `COOP`/`COEP` to `unsafe-none`. **Effort:** small (watch LIFF WebView).

### Low

10. **Webhook GET `/api/line/webhook` → 200** for LINE console Verify. Expected.
11. **ILIKE `%` / `_`** in catalog keywords. Clip/escape wildcards if abused.
12. **Payment / order IDs use `Math.random()`** (predictability). Use `crypto.randomUUID()`.
13. **Discord messaging** is not implemented (docs/specs only). When added: bot token server-only, verify Discord signatures, no `NEXT_PUBLIC_` token.
14. **`EventJsonLd` uses `event: any`**. Type it when used.
15. **CodeQL Action 4.38.0** vs 4.38.3 — already tracked by PRs #29/#30.
16. **`pnpm audit` noise (not production request path):** 29 critical / 200+ high after this pin, almost all **toolchain**: Orval codegen RCE (untrusted OpenAPI → generated files), Vitest UI file-read, Vue CLI `handlebars`, Angular CLI `piscina`/`tar`/`@modelcontextprotocol/sdk`, `@swc/cli` decompress/piscina. **Nx 21.4** [GHSA-w3vv-58gj-gw77](https://github.com/advisories/GHSA-w3vv-58gj-gw77) (local daemon sockets) needs **Nx ≥ 22.7.9** — a workspace migration, not a patch. **Express `path-to-regexp` ReDoS** sits under Nest 10; wait for Express 4 patch or Nest 11 rather than a forced override.
17. **swiper incomplete-fix variant** (override `Array.prototype.filter`, reported through 12.1.4). Needs a later 12.1.x once published.
